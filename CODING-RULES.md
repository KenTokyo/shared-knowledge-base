# Coding Rules

- **Status:** optionale „könnte“-Tipps; bessere Lösung → Vorrang
- **Qualitätslatte könnte:** sichtbar oder messbar
- **Loop könnte:** größte belegte Lücke → Fix → gleicher Vergleich → Wiederholung
- **Deckel könnte:** [3–5 Verbesserungen pro Achse](agents/MAX-5-VERBESSERUNGEN-DANN-WEITER.md), dann etwas Neues
- **Critic könnte:** echtes Artefakt statt Aufwand oder Absicht bewerten
- **Integration könnte:** parallele Ergebnisse auf Kohärenz prüfen
- **Echtzeit-3D könnte:** nur den berührten [Fachowner](THREEJS-RULES.md) öffnen
