# Wildcore: Bloom Siege — Asset Manifest

## Shared Generation Rules

- Built-in image generation, one independent call per image.
- Use case: `stylized-concept`, except explicit interface screens use `ui-mockup`.
- Intended output: polished 16:9 landscape game-development reference.
- Keep one solarpunk-fantasy language, consistent heroes, living Core, materials, and camera family.
- Elevated three-quarter 3D perspective; compact articulated voxel-like heroes with expressive motion.
- Original designs only; no brand marks, copied fantasy UI, famous characters, watermarks, signatures.
- Catalogue images show at most six isolated designs.
- Use coral for Core, jade for growth, gold for choice/electricity, violet for gravity/threat.
