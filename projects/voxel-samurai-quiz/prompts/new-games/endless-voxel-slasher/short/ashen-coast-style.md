# Ashen Coast Style — Short New-Game Prompt

**Use:** Copy the complete block for a compact high-level build request.

```text
I want you to build a completely new browser-based third-person endless action RPG with the combat responsiveness, full-body animation quality, and layered spectacle associated with Black Desert, translated into an original premium voxel style. Do not copy assets or proprietary content. Everything the player reads must be in English. Include exactly two compact selectable worlds—Skyglass Aqueduct Palace and Verdant Titan Grove Fortress—one voxel samurai swordfighter, eight skills on Q/E/R/1/2/3/4/5, ten stone-creature enemy species, endless waves, and a mandatory alternating boss every fifth wave.

Movement must include sprint, responsive jump, a separate dodge roll, and Q as a real directional dash skill usable on ground and in air. Skyward Fang must have a true airborne descending branch so jumping connects to combat rather than acting as decoration. Use articulated full-body voxel rigs with correct pivots, planted locomotion, airborne center-of-mass motion, hip/chest counter-rotation, weapon anchors, anticipation, contact, and follow-through.

Research the strongest relevant local VFX examples and current engine guidance before building combat effects. Every slash must be premium and causally layered from sampled blade motion: depth-capable impact mass, HDR edge core, tapered ribbon trail, readable directional arc, restrained halo, contact flash, material-specific sparks/debris, wind or distortion, short pooled light, ground response, enemy reaction, hit stop, camera impulse, and spatial audio. Never hide the character or target behind bloom or flat glowing planes.

Use the local V73 Ashen Coast AEON implementation only as an architectural reference: authored WorldSpecs, deterministic staged bakes, shared terrain queries, derived water, site-batched structures, biome-driven vegetation, centralized Environment lighting, and a bounded runtime InteractionField. Keep V73 unchanged and make Skyglass and Verdant original specs rather than coastline copies.

Build the complete playable product, not a demo. One linear integration owner must loop through real code and static evidence until every technically verifiable gap is closed. Keep map residues bounded and resettable, pool transient effects, cap enemies and lights, and design for stable 240 FPS without claiming unmeasured performance. Do not start subagents, browser checks, screenshots, gameplay tests, or FPS measurements unless the current user explicitly requests them; leave visible combat feel as an honest manual acceptance gate.
```
